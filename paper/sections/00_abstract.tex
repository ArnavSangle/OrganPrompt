Dense per-voxel annotation remains the binding constraint on CT segmentation.
Labeling a structure requires a reader trained in cross-sectional anatomy, and
the effort scales with every additional structure and volume, so models exist
only where a dedicated annotation campaign has been justified. Vision--language
pretraining suggests an alternative, in which a structure is specified by name
instead of pixel-wise contours. Such models supply semantic knowledge but not
spatial grounding: their contrastive objective aligns pooled embeddings, so no
patch token need be spatially discriminative, and gradient saliency on a
pretrained model recovers 0.003 mIoU. Existing text-driven methods restore
accuracy with a second-stage mask refiner, placing the decisive component beyond
the reach of the prompt. This work instead makes spatial discriminability an
explicit training objective, aligning each patch token with the organ's text
embedding
against a downsampled mask, so that per-patch cosine similarity becomes readable
as a segmentation map without gradients, a classifier, or a mask refiner. On 11
TotalSegmentator organ classes this reaches 0.653 mIoU without per-pixel labels.
The accuracy gain over comparable weakly supervised work is modest, but the gain
in interpretability is substantial. Because the prompt is the only input, its
contribution is directly measurable: corrupting positional language
collapses exactly the classes that depend on laterality. A two-word prompt error
produced a confident, clean segmentation of the wrong organ: failures are
directional rather than degradative, and nothing in the output signals them.
Carried unmodified onto an unseen cohort, the model ranks the organ nearest a
spinal metastasis well above chance.
